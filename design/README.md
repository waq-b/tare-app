# Design source: Tare v1

Export of the Tare v1 design canvas (22 Sep 2026): 60 boards plus `canvas.json`, which holds the pages, board titles and layout.

- These files are read-only reference. They are inline-styled HTML, so treat them as a visual spec
- Pages: Brand + system (Names, Tokens, Components, Icons, Charts) · Active workout · Screens · Body, food + alerts · Prototype (Flow)
- Chosen workout direction: Ledger (`Workout-A*`)
- Where the canvas uses placeholder copy, the app uses the dataset's wording instead; `docs/DESIGN.md` §5 lists the differences
- If the design changes, re-export and overwrite this folder
